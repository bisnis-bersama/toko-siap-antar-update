PENAMBAHAN RULES FIRESTORE — Toko Siap Antar (jangan mengganti rules yang sudah ada)

1) Pada match /orders/{docId} yang SUDAH ADA, tambahkan kondisi mitra pada allow read dan allow update. Karena Firestore menggabungkan allow dengan OR, aturan ini dapat ditambahkan sebagai baris allow terpisah di dalam blok match /orders/{docId} yang sama:

      // Mitra hanya dapat membaca order yang ditugaskan kepadanya.
      allow read: if request.auth != null
        && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == "mitra"
        && resource.data.mitraUid == request.auth.uid;

      // Mitra hanya boleh mengubah status pengantaran pada order tugasnya.
      allow update: if request.auth != null
        && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == "mitra"
        && resource.data.mitraUid == request.auth.uid
        && request.resource.data.mitraUid == resource.data.mitraUid
        && request.resource.data.diff(resource.data).affectedKeys().hasOnly([
          "statusPengantaran", "updatedAt", "mitraLastUpdateBy"
        ])
        && request.resource.data.statusPengantaran in ["DIAMBIL", "DALAM_PENGANTARAN", "SELESAI"]
        && request.resource.data.mitraLastUpdateBy == request.auth.uid;

2) Untuk query halaman mitra, dokumen order harus punya mitraUid yang sama dengan UID mitra. Jangan membuat rule global allow read untuk semua order.
3) Halaman mitra-admin.html mengharuskan role users/{{UID}}.role == "superadmin". Admin menetapkan mitraUid pada dokumen order.
4) Buat akun mitra lewat Firebase Authentication. Setelah akun dibuat, buat/perbarui dokumen users/{{UID}} dengan field role: "mitra", nama, telepon, email. Jangan memberikan role mitra kepada akun pembeli.
5) Aturan /users/{uid} yang sudah ada membatasi pembuatan user ke role owner. Pembuatan dokumen role mitra harus dilakukan oleh superadmin melalui proses admin yang aman atau konsol Firebase, bukan oleh form publik.

PENTING: aturan /orders yang lama mengizinkan owner/superadmin. Penambahan allow di atas harus dimasukkan ke dalam blok match /orders/{docId} yang sudah ada sebelum blok DEFAULT DENY. Jangan hapus atau mengganti aturan aplikasi lain. Uji dahulu di Firebase Rules Playground.
